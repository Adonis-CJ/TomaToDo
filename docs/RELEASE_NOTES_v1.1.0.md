# TomaTodo v1.1.0 — 墨·纸 2.0 优化版

> 在 GitHub Releases 页面（Releases → Draft a new release → 选择已推送的 tag `v1.1.0`）将本文件内容粘贴到描述中即可发布。可同时上传 `app-debug.apk` 作为附件。

## ✨ 亮点

在 v1.0 全功能 MVP 基础上，本版本完成「墨·纸 2.0」UI 升级与功能闭环，清零 13 项技术债中的 12 项。

### 卡片知识管理（全新）

- **分科目管理**：科目筛选 Chip 行（色点 + 计数）+ 网格 / 按科目分组双模式
- **专属撰写页**：全屏编辑，平板横屏双栏（左表单 / 右实时预览翻转）；科目前置色块选择器、标签、来源
- **图片升级**：拍照 / 相册自动压缩（长边 1600px / Q85）、单张删除、全屏双指缩放查看器
- 数据库 v2：卡片标签、复习历史表（ReviewRecord），无损自动迁移

### 看板改版

- **三态视觉语言**：状态色条 + 三态勾选框（完成白勾描边动画）+ 划线变灰 + 进行中朱砂描边
- **日期导航**：`← 日期 →` 任意跳转 / DatePicker 选日；历史回顾只读、未来预排可编辑；「回到今天」
- 今日进度头部（x/y + 动画进度条）、滑动删除 + 撤销、空列插画
- 一键「开始番茄」：自动关联任务并置为进行中

### 番茄钟闭环

- 铃声 / 音量真实生效（三档音色），静音 + 仅震动图书馆友好
- 悬浮窗权限引导弹窗；通知权限动态申请；通知刷新降频至 1Hz
- 完成番茄自动累加任务番茄数

### 复习升级

- 单卡沉浸刷题模式（进度 x/y + 完成小结）
- 复习历史留痕；到期列表跨天自动刷新

### 统计可视化（全新）

- 近 30 日专注柱状图（今日高亮、点选查看）
- 科目分布环形图（科目标色 + 图例）
- 12 周打卡热力图（GitHub 风格）
- 按科目任务完成率条形图
- 日 / 周 / 月范围切换 + CSV 导出 + 周报系统分享

### UI 与体验

- **品牌字体**：标题 Noto Serif SC（思源宋体）+ 数字 IBM Plex Mono
- 设置页分组卡片化 + 步进器（± 按钮）+ 主题迷你预览卡
- 窗口 insets 适配、跨列 / 切日 / 勾选动效
- SVG 自适应应用图标「番茄即钟」+ Android 13 主题图标

### 数据安全

- 备份升级为 ZIP（含卡片图片），导入自动兼容旧版 JSON

## 📦 安装

下载下方 `app-debug.apk` 安装到 Android 8.0+ 设备（平板体验最佳），或自行从源码构建。
