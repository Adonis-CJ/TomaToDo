# TomaTodo v1.1.1 — 看板 / 番茄钟 UI 打磨版

> 在 v1.1.0 基础上，聚焦看板与番茄钟的视觉与交互打磨，全部功能经真机验证。

## 🎯 番茄钟

- **双沉浸模式**：翻页钟（台历式）+ 背景图时钟，可在番茄页一键切换
- **台历式翻页钟**：只动上半片绕水平中轴向下翻（0→-180°），下半静止；数字在卡片中线正确截断（不再复制两份）；后半段镜像抵消反字
- **背景图时钟**：自定义壁纸 + 中心圆环倒计时
- **任务选择器**：番茄页顶部可选/换绑当前关联任务
- **专注不可跳过**：跳过按钮仅休息阶段显示
- **3 秒自动进入全屏沉浸**，轻触呼出控制层
- **悬浮窗**：仅应用进后台时出现（番茄造型：朱砂卡 + 白等宽时间 + 暂停/继续 + 关闭，点击返回应用），权限缺失时引导开启

## 📋 看板

- **任务卡**：清晰的 16dp 圆角矩形、白卡浮出深色列底（对比明显）、三态视觉（左缘状态色条 + 勾选框 + 完成划线降透明）、等宽时间不跳动
- **三列可滚动**：任务多时在列内上下滑动，不溢出
- **日期导航**：`← 日期 →` + DatePicker 任意历史/未来日，历史回顾只读、未来可预排
- **科目筛选**：全部 / 各科 / 未分类
- **结束时间支持日期**：先 DatePicker 选日期再选时分，跨天任务可正确设置
- **滑动删除 + 撤销**（背景圆角化，无尖角矩形）

## 🧩 新增

- **侧边栏考研倒计时**：顶置「距考研 N 天」（倒计至 2026-12-19）
- **看板寄语**：标题右下角内联 `Motto: ` 前缀，宋体放大；可在设置中自定义，留空则每日轮换格言

## 🛠 技术

- 品牌字体落地：Noto Serif SC（标题/寄语）+ IBM Plex Mono（数字/时间）
- 全部功能真机（华为平板）验证

## 📦 安装

下载下方 `app-debug.apk`（36MB，含字体）安装到 Android 8.0+ 设备（平板体验最佳），或自行从源码构建。
